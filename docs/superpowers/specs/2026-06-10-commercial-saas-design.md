# LynxAgent 商用化设计（个人订阅 SaaS）

日期：2026-06-10
状态：已确认（Allen 逐节审批通过）

## 背景与决策

- **目标仓库**：LynxAgent（法律干净、完全自有）。TradingAgents 仓库的 `app/`+`frontend/` 为 hsliuping 专有代码，商用需单独授权，故 TradingAgents 仅作开发试验场，功能验证后同步至此。
- **商业模式**：个人订阅 SaaS——部署到云服务器，散户投资者按月/年付费。
- **合规定位**：AI 研究工具（量化研究终端）。只提供数据、信号与 AI 分析过程，不提供买卖建议。
- **路线**：最小商用闭环（方案 A），三个里程碑（能收钱 → 能见人 → 能留人），每个里程碑均为可发布状态。

## §1 收钱基建

### 配额体系（最优先，成本安全阀）

- SQLite 新增两张表：
  - `plans`：套餐定义（名称、每日 LLM 次数、功能开关）
  - `usage_log`：每次 LLM 调用记录（user_id、动作类型、时间、token 成本估算）
- **只对烧钱动作计费**：个股深研报告、深研辩论、serenity 深度报告、AI 因子生成。行情/K线/列表类不限。
- 中间件实现：调用前查当日余额，不足返回 `402` + 前端引导升级；调用后记账。
- 用户菜单角落常显「今日剩余次数 N/M」，点开见明细。

### 套餐（两档）

| | 免费版 | 会员版（~¥39-69/月，定价后议） |
|---|---|---|
| 行情/涨停/热点/选股池 | ✅ 全开 | ✅ |
| LLM 深度分析 | 3 次/天 | 30 次/天 |
| 催化剂深度报告 | ❌ 只看事件卡 | ✅ |
| 价格预警推送 | ❌ | ✅ |
| 回测/因子实验室 | ❌ | ✅ |

### 支付：手动开通起步

- 第一阶段不接支付 API：「升级会员」页放微信收款码 + 联系方式，收款后管理后台手动开通。
- `users` 表加 `plan` + `plan_expires_at` 字段，到期自动降回免费。
- 聚合支付（虎皮椒/payjs 等）待 20+ 付费用户后再接。

### 管理后台（极简，单页面）

- 仅 admin 可见：用户列表（套餐/到期日/今日用量/累计用量）、改套餐、禁用账号。
- 不做图表仪表盘。

## §2 合规清洗

### 文案清洗（一次性全站）

| 现有表述 | 改为 |
|---|---|
| `position_note`「建议轻仓/加仓/止损」 | 重命名为 `tracking_note`，只给观察点与证伪信号，不给动作；LLM prompt 同步改措辞 |
| 产品自产「买入评级/目标价」 | 不出现（新闻原文转述可保留） |
| 「今日机会」 | 「今日聚焦」/「今日信号」 |
| 「利好监控」 | 「催化剂监控」 |

做法：grep 全站中文文案 → 清单化逐条改，prompt 层一并改。

### 砍掉模拟交易（PaperTrading）

- 菜单移除 + 路由下线，代码保留不删（只断入口）。
- 理由：「下单/持仓/盈亏」界面易被认定为诱导交易，且依赖 easytrader 桥接真实券商接口。

### 法务三件套

- 免责声明：注册时弹窗强制勾选 + 每份 AI 报告头部固定免责行。
- 用户协议 + 隐私政策：静态页，注册勾选。AI 起草初稿，**最终需人工法务审一遍**。
- **ICP 备案**为上线前置项（个人备案，周期 1-2 周），尽早启动。

### AI 输出边界

- 所有 LLM 报告结尾由**代码层拼接**固定免责段（不靠模型自觉）。
- 事件层评分（七维评分、重要性分）保留；个股层不出现「综合评分 → 建议」映射。

## §3 UX 商用打磨

### 信息架构：13 项平铺 → 4 组动线

```
📍 今日          —— 新首页
📊 市场          —— 市场雷达 / 涨停热点 / A股热点 / 催化剂监控
🎯 选股          —— 智能选股 / 催化剂选股
🔍 个股          —— 个股深研 / 深研辩论
⭐ 我的          —— 自选股 / 组合体检 / 会员与用量
————————————————
🧪 实验室（会员） —— 因子实验室 / 回测实验台
⚙️ 数据中心      —— 收进「我的」或管理员可见
```

### 新首页「今日」（最重要新增页）

回答「今天打开，30 秒内我该看什么」：

- 顶部一句话市场定调（加权情绪分 → 一行自然语言 + 红绿灯）。
- 三张卡片：催化剂事件 TOP3（七维分排序）/ 涨停热点梯队 / 自选股异动。
- 首页是分发器，点卡片进详情页，不堆细节。

### 等待体验（实测 25s+ 裸等待）

- LLM 深度分析改分步进度：「①获取数据 → ②分析传导链 → ③独立复核」逐步点亮。
- 后端长接口拆为「提交任务 + 轮询状态」。
- 超 60s 任务允许离开页面，完成后站内通知。

### 报告呈现（实测裸 JSON）

- serenity 深度报告抽屉卡片化：传导链 = 步骤条、受益股 = 表格带证据等级 tag、红旗 = 红色警示条、独立复核 = alert 保留。
- 与个股深研 HTML 报告风格统一。

### 首次体验 + 术语清洗

- 新用户三步引导：看今日 → 加自选 → 跑一次深度分析（送 3 次）。
- 空状态治理：无数据时给「这是什么 + 怎么开始」。
- 界面术语清洗："serenity" → 「事件引擎」、"smart-pool" → 「智能池」等；七维评分各维度加悬停解释。
- 移动端：核心四页（今日/催化剂/自选/个股报告）响应式可读，不做 App。

## §4 功能对齐与取舍

### 从 TradingAgents 同步（按价值排序）

| 功能 | 说明 | 成本 |
|---|---|---|
| serenity 七维评分版 | 七维加权+证据阶梯+噪音预过滤+独立复核（含 review `max_tokens` 700→1200 修复） | 低 |
| 加权情绪 + 智能池因子 | 个股/大盘/板块三层加权 | 低 |
| 投资者画像 + 红旗扫描 | 个股深研增强 | 中 |
| 资金面板（capital_flow） | 大盘情绪页资金维度 | 中 |

同步时一并做 §2 文案清洗与 §3 术语清洗，一次过手不返工。

### 新增：微信推送（唯一全新功能，留存关键件）

- 价格预警、自选股命中 serenity 事件时推送。
- 实现走 Server酱/PushPlus（用户扫码绑定，零审核零成本）。
- 会员专属——订阅续费的核心钩子。

### 明确不做（YAGNI）

- ❌ 模拟交易（§2 已定）
- ❌ 实时行情/Level-2（数据授权费过高）
- ❌ 港美股（聚焦 A 股）
- ❌ 社区/评论（内容合规无底洞）
- ❌ App/小程序（响应式 Web 够第一年；小程序金融类审核极不友好）
- ❌ 多 LLM 切换界面（后台配置即可）

## 里程碑

```
M1 能收钱（~2周）：配额体系 + 双套餐 + 手动开通 + 管理后台 + 文案合规清洗
M2 能见人（~3周）：新首页「今日」+ 菜单重组 + 报告卡片化 + 等待进度 + 功能同步
M3 能留人（~2周）：新手引导 + 空状态 + 微信推送 + 移动端响应式 + ICP备案落地
```

M1 完成即可熟人付费内测。

## 验收标准

- M1：免费账号当日第 4 次深度分析被拦截并引导升级；admin 后台可改套餐并立即生效；全站无「建议仓位/加仓/止损」表述。
- M2：新注册用户落地「今日」页 30 秒内可理解市场状态；深度报告无裸 JSON；LLM 等待有分步反馈。
- M3：会员绑定推送后，自选股命中事件可在 1 分钟内收到微信通知；手机浏览器核心四页可读。
