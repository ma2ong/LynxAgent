# 选股规则有效性验证报告（2026-07-13）

数据源：历史回放 run `20260713-091616`（本地日线 point-in-time，2025-05-30 ~ 2026-06-18，52 期采样、每期 top20、T+5 对全市场中位超额），已回填「次日开盘可成交」口径。

## 结论速览

| 池 | 结论 | 依据 |
|---|---|---|
| **形态智选（pattern）** | **组合层面有效，单票无效** | 可成交口径平均超额 +1.74pp/期、12/14 个月为正；但中位 -0.52pp、胜率 48.2%，收益全靠右尾 |
| **智能推荐（smart）** | **组合层面弱有效（近似口径存疑）** | 可成交口径平均 +1.37pp/期；中位 -0.03pp、胜率 49.6%；评分输入为日线近似重建，置信度低于 pattern |
| **短线波段 / 竞价优选** | **未验证** | 依赖盘中实时行情（分时/竞价快照），日线无法 point-in-time 重建，只能靠实盘留痕积累（当前 30 天样本均为负超额，弱市期，样本不足下结论） |

## 三个关键判断

1. **超额存在，且不是涨停幻觉**：pattern 池 42.6% 的入选票收盘已涨停买不到回测价，但换成次日开盘可成交价后平均超额仅从 +2.00 降到 +1.74——强势票次日仍在延续，规则捕捉的是真实动量。
2. **收益结构是「彩票组合」**：单票胜率 ≈ 抛硬币、中位为负，平均为正靠约 10% 的大涨票（p90 +17.8）。**用户行为含义：必须整池等权买入（产品已提供「整池加入组合」一键动作），单挑一两只大概率体验为亏。**
3. **回放与近期实盘留痕的落差是市场环境**：近 30 天留痕三池 T+5 超额全为负（smart -5.6pp），同期全市场普跌（近5日中位 -3.7%、上涨占比 22%）。回放轴截止 2026-06-18，未覆盖 7 月初的暴跌段。弱市短线信号系统性失效与「大盘环境：偏冷」提示一致——这不推翻 12 个月结论，但确认了**环境择时比选股本身更重要**。

## 已知局限（解读时必须记住）

- **存活偏差**：回放宇宙为当前在库股票，期间退市股未包含（A 股年退市几十只，偏差方向为高估）。
- **smart 池近似口径**：量比/换手率由日线重建，critic 融合层跳过，与线上实际评分有差异。
- **无换手成本**：回放统计的是信号层收益；模拟组合含真实 A 股交易成本，长期跟踪以组合 NAV 为准。
- **排除规则用当前股票名称**：历史时点的 ST 状态无法还原。
- 每期 top20 × 每 5 日调仓意味着近乎全换手，实盘按 +1.74pp/期扣除双边成本（约 0.13pp）后仍为正，但滑点未计。

## 补充：轴敏感性检验 + 大盘环境分层（同日第二次回放，run 20260713-142305）

第二次回放把会话轴前移约 3 周（2025-06-03 ~ 2026-06-22，T+5 窗口延伸进 7 月初暴跌段），结论出现实质变化：

| 可成交口径 T+5 | run 091616（轴至 06-18） | run 142305（轴至 06-22，含暴跌尾段） |
|---|---|---|
| pattern 平均 / 中位 | +1.74 / -0.52 | **+0.76 / -0.68** |
| smart 平均 / 中位 | +1.37 / -0.03 | **+0.21 / -0.75** |

大盘环境分层（142305，收盘口径，环境=入选时点近5日全市场中位+上涨占比，阈值与线上横幅同源）：

| 环境 | pattern 均/中位/胜率 | smart 均/中位/胜率 |
|---|---|---|
| 偏暖（14期） | +2.35 / +0.87 / 54% | -0.23 / -1.11 / 41% |
| 中性（22期） | +0.82 / -1.70 / 41% | +0.27 / -1.09 / 40% |
| 偏冷（16期） | +0.40 / -2.10 / 44% | **-0.16 / -0.66 / 46%** |

**结论修正（以更严苛的数据为准）**：

- **pattern：弱有效且环境敏感**。均值随窗口从 +1.74 缩到 +0.76，偏暖期 +2.35 是主要收益来源，偏冷期均值贴零、中位 -2.10——弱市轻仓或观望。
- **smart：无稳定超额，降级为「无效边缘」**。换轴后均值贴零、偏暖期反而为负；此前 +1.37 的结论对样本窗口高度敏感，不足以支撑跟随。
- **窗口敏感性本身是核心发现**：3 周轴移即可让结论翻转，说明 52 期采样的统计功效有限。任何单次回放数字都不应作为营销承诺，产品页展示「最新一次回放 + 分环境 + 双口径 + 中位数」的组合，让用户看到全貌。

产品落地（批次 F，已实现）：复盘页每池「分环境表现」表；结论卡按数据自动追加「弱市停跟/轻仓」建议（smart 偏冷均值<0 → 停跟；pattern 偏冷缩水过半 → 轻仓）；选股页大盘环境横幅在「偏冷」时引用回放证据（当日实测：中位 -6.25%、上涨占比 14%，横幅正确展示两池偏冷期数据与「只跟不买」建议）。
