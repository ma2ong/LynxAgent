# 七不买避雷 + 三不卖形态 设计（2026-07-17）

## 背景

Allen 提供了「三不买七不卖」口诀、相对强度选股、板块轮动等素材，要求：
1. 把「七不买」做成避雷功能（形态 + 资金/量能/情绪角度），给出买卖建议；
2. 把「三不卖」的三个图形并入形态智选。

## 数据边界（先说不能做什么）

- **利好公开不买**：需要可靠的个股新闻-价格对齐数据，现有事件引擎覆盖面与时效不足以支撑
  逐股判定，硬做会大量误报。**不做**，spec 记录，等新闻源成熟另立项。
- **竞价 9:15-9:25 四种量价形态**（主力抢筹/诱多出货/洗盘低吸/多空分歧）：需要竞价时段的
  逐分钟撮合时序，现有竞价模块只有最终快照。**不做**，需先建盘口时序采集，另立项。
- **问题股（处罚/造假）**：无监管处罚数据源；用现有代理指标——ST 名称 + 业绩预亏预减
  （fundamental_flags），能挡住大部分。

## 批次 A：七不买避雷（risk_check）

新模块 `quantcore/quant/risk_check.py`，纯函数、仅用日线 + 可选实时 quote，全部可测：

| 规则 | 判定（板块感知）| 等级 |
|---|---|---|
| 急涨后高位 | 近10交易日累计涨幅 ≥ 涨停幅×5（主板50%/创科100%）且期间最大回撤 <8% | 风险 |
| 长期横盘 | 近60日振幅 (max−min)/min < 12% | 提示（注：大基底盘整突破前反而是机会，故不判为雷）|
| 天量 | 当日量 ≥ 前5日均量×4 且收盘处于近60日 80 分位以上；有实时换手率时叠加 ≥8% | 风险 |
| 高位滞涨 | 近5日均量 ≥ 再前5日×1.5 且近5日涨幅 <2% 且处于60日 80 分位以上 | 风险 |
| 破位 | 收盘 < MA10 且 < MA20 | 风险 |
| 问题股 | 名称含 ST/退 或 业绩预亏预减标记 | 风险 |
| （已有）涨停买不到 | limit_up 标注继续沿用 | 提示 |

输出：`check_risks(symbol, name, df, quote?, bad_forecast?) -> {flags: [{key,name,level,reason}], advice, risk_count}`。
advice 规则：≥2 风险 →「回避：命中 X 项风险」；1 →「谨慎：…」；0 →「未命中七不买风险项」。
一律附「规则化提示，不构成投资建议」。

落点：
- **选股池行内**：smart/pattern 扫描 worker 内已有截断日线，顺手算 flags（零额外 IO），
  行内新增红色「雷」标签（悬停看明细）。池子本就排除 ST/预亏，主要暴露急涨/天量/滞涨/破位。
- **个股深研**：`GET /api/quant/risk-check?symbol=`（日线 + 实时 quote 全量判定），
  深研页加「七不买体检」卡片——用户查自己想买的票，这是避雷的主场景。

## 批次 B：三不卖形态 → 形态智选

`integrations._detect_pre_lift_patterns` 新增三个低位看多形态（与现有形态同结构，自动进
形态池扫描与回放）：

| 形态 | 判定 |
|---|---|
| 三军会师 | MA5>MA10>MA20 多头排列、三线近5日内完成金叉、且价格处于250日区间下半区 |
| 双管齐下 | 近3根内出现两根长下影（下影≥实体×2）小实体K线，两下影最低点相差<1.5%，处于120日低位 |
| 五阳上阵 | 连续5日收阳、每日实体≤3%、5日累计涨幅<12%、处于120日低位 |

- SCAN_VERSION 3→4（形态候选集变化，回放断点作废重扫）。
- 部署后启动一次回放，重新验证形态池（新形态的历史 T+5 超额会自动进入 signal-stats 与理由卡）。
